# 产品需求文档（PRD）：vedio-website 个人视频网站

- 文档版本：v1.0（基于现有已发布能力反向梳理的基线 PRD）
- 产品定位：面向 NAS 的轻量个人视频网站
- 适用对象：需求提出方、PM、开发、验收方
- 配套文档：[需求管理流程与 PM 把关规范](./01-需求管理流程与PM把关规范.md)、[路线图与需求池](./03-路线图与需求池.md)
- 约定：标注 **[需 DB]** 的能力依赖 `DB_PATH`；**[需 TMDB]** 依赖 `TMDB_API_KEY`；**[需转码]** 依赖 ffmpeg 且转码开关打开。未启用时按各自降级规则处理。

---

## 1. 背景与问题陈述

### 1.1 背景
个人与家庭用户在 NAS 上沉淀了大量电影、剧集视频（MKV/HEVC 等容器居多），通用方案（Jellyfin/Emby/Plex）体量重、数据库与转码链路复杂、资源占用高，且对"零数据库、单二进制、低配设备"场景不友好。

### 1.2 核心问题
1. 浏览器无法直解 MKV/HEVC/FLV 等容器，需要按需转码且要能在低配 NAS 上受控运行。
2. 希望像影视站一样有海报墙、元信息、剧集分组、断点续播，但又不想被重型数据库绑定。
3. 局域网/远程观看需要续播、收藏、清单、分享、观影记录等个性化能力，且这些能力应"可选启用、缺省降级"。
4. NAS 网络盘（NFS/SMB）文件事件不可靠，媒体库需在监听之外具备兜底一致性。

### 1.3 产品目标
- **开箱即用**：单容器、单二进制、零数据库默认可跑，挂载目录即出片库。
- **按需重活**：转码、刮削、OCR 等高资源能力全部可选、可限流、可降级。
- **能力渐进**：基础浏览播放零依赖；个性化与分享能力在开启 SQLite 后平滑解锁。
- **家庭可用**：响应式暗色界面、键盘快捷键、字幕/音轨/清晰度齐全，桌面与手机一致体验。

### 1.4 非目标（明确不做）
- 不做多租户、多用户账号体系与社交关系（当前为单密码访问的个人/家庭站）。
- 不做云端转码/分布式转码、不做离线下载器。
- 不内置付费、广告、内容分发（CDN）能力。
- 不强制依赖数据库；不以引入外部前端构建链为目标。

## 2. 目标用户与场景

| 角色 | 特征 | 核心场景 |
| --- | --- | --- |
| 站长（Owner） | 部署运维者，掌握 NAS 与环境变量 | 部署、配置转码/刮削、管理片库与数据健康、生成分享 |
| 家庭成员（Viewer） | 普通观看者，手机/电视浏览器 | 浏览海报墙、续播、追剧连播、切字幕音轨清晰度 |
| 访客（Guest，匿名） | 拿到分享链接的站外人员 | 凭链接/口令在线预览或下载单个视频，无需登录 |

关键用户故事（节选，完整故事随需求卡在 `requirements/` 沉淀）：

- 作为站长，我希望挂载目录后自动出片库，以便不做手工导入。
- 作为观看者，我希望下次打开自动从上次位置续播，以便长视频不用拖动找回。
- 作为观看者，我希望剧集自动分组并连播下一集，以便追剧不打断。
- 作为站长，我希望生成带有效期和口令的分享链接，以便安全分享单个视频。
- 作为低配 NAS 用户，我希望转码有并发上限和空闲回收，以便不卡死整机。

## 3. 产品形态与技术约束（PM 必须知晓的边界）

- Go 后端 + 原生 Web 前端，`html/template` 服务端渲染（SSR），模板与静态资源 `go:embed` 内嵌。
- 路由基于 Go 1.22+ 增强 ServeMux；JSON API 与 SSR 页面并存。
- 媒体索引在内存，ID 由相对路径 SHA-1 派生，重扫稳定；仅 `DB_PATH` 显式启用 SQLite（纯 Go 驱动，无 CGO）。
- 所有可选能力遵循"未启用即降级"：API 返回 503、UI 隐藏入口或显示友好提示。
- 详细环境变量与 API 清单以仓库 [README](../../README.md) 为权威，本 PRD 仅描述产品行为契约。

## 5. 功能需求（按模块，含验收要点与降级）

> 每个模块给出能力与关键验收契约；详细 Given/When/Then 在对应需求卡与 HTTP 测试中固化。

### F1 媒体库扫描与一致性（零依赖）
- **F1.1 递归扫描**：启动全量扫描，识别 mp4/mkv/mov/avi/webm 等扩展名，建立内存索引（ID=相对路径 SHA-1）。
- **F1.2 文件监听增量**：fsnotify 递归监听新增/删除/重命名，防抖后增量入库，避免拷入半截文件；NAS 晚挂载自动重试。
- **F1.3 定时兜底**：`RESCAN_INTERVAL` 开启定时全量扫描，覆盖 NFS/SMB 事件丢失。
- 验收要点：增删改名后片库即时一致；重扫后 ID 稳定；`POST /api/v1/rescan` 触发重扫并清理孤儿持久化记录 [需 DB]。

### F2 浏览、检索与组织（部分零依赖）
- **F2.1 首页卡片墙**：海报优先、缩略图回退；电影/剧集视图切换；排序（名称/最新/最旧/大小）。
- **F2.2 正交筛选**：关键字 `q`、类型 `genre`、标签 `tag`[需 DB]、类型片 `type`、视图 `view` 可组合，URL 可书签化。
- **F2.3 横向片架**：干净默认视图展示"继续观看"[需 DB] 与"最近加入"（按 ModTime，零依赖）。
- **F2.4 目录浏览/搜索/智能清单**：`/browse` 按物理目录；`/search` 检索；`/smart` 实时规则视图 [需 DB]。
- **F2.5 新片时间线** `/new`：按文件 ModTime 分"最近 7 天/最近 30 天/更早"，组内倒序；30 天窗口内卡片打"新"角标（零依赖、零额外存储）。
- **F2.6 随机看看** `/random`：后端随机推荐，零依赖。
- 降级要点：未启用 DB 时标签/收藏/续播视图与片架隐藏，浏览/搜索/时间线/随机仍可用。

### F3 播放体验（核心，零依赖起）
- **F3.1 流式播放**：HTTP Range 流式 + 浏览器原生播放器；`?download=1` 触发下载。
- **F3.2 播放控制**：0.5–2 倍倍速、键盘快捷键（空格/K、←→±5s、↑↓音量、F 全屏、M 静音）、字幕字号三档。
- **F3.3 断点续播** [需 DB]：每 5 秒/暂停/切后台/关闭自动上报进度，重开自动续播；≥95% 视为看完从头播；片头抖动（<5s）不计入续播。
- **F3.4 剧集连播**：本集 ended 弹 5 秒倒计时自动跳下一集（跨季顺延），可取消；末集/电影不弹。
- **F3.5 列表连播** [需 DB]：带 `?playlist=` 时按列表顺序连播，末项停止不回退，悬空条目跳过。
- **F3.6 睡眠定时**：固定 15/30/60 分钟 + "本集结束自动暂停"档；会话级、不持久化；视频时长未知时拒绝本集档并提示改用固定档。
- **F3.7 片头片尾跳过** [需 DB]：可配置 intro 跳过秒数。
- **F3.8 书签/时间戳笔记** [需 DB]：在时间点创建/编辑/删除书签，`/bookmarks` 集中管理。

### F4 转码与播放增强 [需转码，整体可降级]
- **F4.1 HLS 按需转码**：浏览器不可直解时 ffmpeg 实时转 H.264/AAC HLS，边转边播；原画零开销为默认入口。
- **F4.2 清晰度档位**：原画直链 + 1080p/720p/480p 手动档；缩放"不放大源"，非法参数归一化 720p。
- **F4.3 自适应 ABR**：单进程多变体 master.m3u8，hls.js/Safari 按带宽切档，会话内可锁档；不自动启用、需显式选择。
- **F4.4 并发与回收**：`TRANSCODE_MAX` 上限、满则排队返回 429、空闲超时停止、再次观看重转。
- **F4.5 硬件加速**：可选 VAAPI（Intel 核显），设备缺失启动期回退软转。
- **F4.6 多音轨**：ffprobe 探测多音轨，master 带 `EXT-X-MEDIA`，播放页切换；单音轨保持简单布局。
- **F4.7 字幕链路**：外挂 SRT/VTT/ASS/SSA 服务端统一转 WebVTT；内嵌文本字幕转码时提取共享；位图字幕经可选 tesseract OCR，缺失静默降级。
- **F4.8 任务管理**：`/transcode/admin` 查看会话、终止并清理。
- 降级要点：无 ffmpeg 或开关关闭时隐藏清晰度菜单，原画/下载/字幕等不受影响。

### F5 元信息与海报（本地零依赖，在线可选）
- **F5.1 本地 NFO/海报**：识别 Kodi/Jellyfin 风格 NFO 与海报/背景命名约定，文件监听自动刷新；`/artwork/*` 白名单+路径穿越防护。
- **F5.2 TMDB 在线刮削** [需 TMDB]：播放页候选搜索、人工确认后下载图片补全；本地 NFO 权威、TMDB 只填空；来源标记 nfo/tmdb/nfo+tmdb。
- **F5.3 批量刮削** [需 TMDB]：仅补全无元信息视频，内存单任务（409 防重）、300ms 节流、进度轮询、失败隔离。
- **F5.4 手动编辑元信息**：依赖可写缓存目录，未配置返回 503。
- **F5.5 影片详情页** `/video/{id}`：聚合海报/简介/年份/类型/演职/文件信息、进度与操作入口；四级"更多类似"推荐（同剧集→共同类型加权→共同标签 [需 DB]→同目录兜底），无候选时隐藏推荐区。
- **F5.6 人物聚合** `/person/{name}`：按演员/导演聚合作品。

### F6 剧集分组（零依赖，内存聚合）
- **F6.1 命名识别**：支持 `S01E02`、`1x02`、中文"第X季第X集"、`EP02` 等；识别失败按电影处理。
- **F6.2 聚合与展示**：同目录规范化剧名聚合，季目录/特辑上提，首页折叠为剧集卡片，详情页按季列集。
- **F6.3 稳定标识**：剧集 ID 由"聚合目录+规范化剧名"SHA-1 派生，重扫稳定，空剧自动清除。

### F7 个性化与持久化 [需 DB，未启用整体降级]
- **F7.1 播放进度**：续播、续播提醒 `/continue`、观影历史 `/history`（可清空/删单条）、CSV 导出。
- **F7.2 收藏**：卡片/详情/播放页收藏切换，收藏视图与角标。
- **F7.3 稍后再看**：加入/移除/收件箱页。
- **F7.4 个人评分**：1–5 星，PUT 设置/再点同档清除/DELETE；`/my-ratings` 聚合 4 星及以上；首页与详情星级角标；未启用 503 且 UI 隐藏。
- **F7.5 标签**：视频打标签、全局重命名/删除、首页批量打标/移除、按标签筛选。
- **F7.6 播放列表/合集**：创建/重命名/删除、加入（去重）、整剧一键加入、手动排序（无间隙整数）、列表连播、JSON 备份导出/导入、独立 SSR 详情页。
- 降级要点：未配置 `DB_PATH` 时以上 API 一律 503，页面入口与按钮隐藏，其余功能不受影响。

### F8 匿名分享 [需 DB]
- **F8.1 创建/吊销**：有效期白名单（1/7/30 天）+ 可选口令（4–64 位，SHA-256 哈希存储，不回显明文）；随机不可枚举 token。
- **F8.2 公开链路**：`/share/{token}` 免登录落地页；口令校验后下发签名 Cookie，支持 `?passcode=` 单次带码（下载工具场景）；下载支持 Range。
- **F8.3 防爆破**：按"来源 IP + token"失败限流，10 分钟错 10 次锁到窗口结束（429），表单与 query 两入口统一计数。
- **F8.4 生命周期**：过期访问 410 并懒清理，定时任务批量清理，源视频删除返回 404；`/shares` 管理中心集中吊销。

### F9 认证与安全（可选）
- **F9.1 访问密码**：设置 `AUTH_PASSWORD` 即开启，HMAC-SHA256 签名 HttpOnly Cookie 无状态鉴权，无需数据库。
- **F9.2 鉴权边界**：除 `/login`、`/healthz`、`/static/*`、占位图、`/share/*` 外均拦截；页面 302 跳登录（带站内 next，防开放重定向），API 返回 401。
- **F9.3 登录防护**：同 IP 失败 10 次锁 10 分钟；`AUTH_SECRET` 固定密钥避免重启掉登录。
- **F9.4 安全基线**：文件类接口路径白名单/穿越防护；分享口令哈希；签名 Cookie；panic 恢复不泄露堆栈。

### F10 运维与可观测（零依赖为主）
- **F10.1 健康探针**：`/healthz` 匿名固定 200，Dockerfile HEALTHCHECK。
- **F10.2 数据/缓存健康**：`/data/health`[需 DB] 清理 SQLite 孤儿；`/cache/health` 清理缩略图/TMDB 孤儿缓存（零依赖）；`/library/storage` 存储分析。
- **F10.3 优雅关闭/日志/恢复**：请求日志、panic recover、优雅退出。
- **F10.4 PWA**：Service Worker 离线壳，静态资源变更须升 `CACHE_NAME` 并同步测试断言。

## 7. 非功能需求（NFR）

| 类别 | 要求 |
| --- | --- |
| 性能 | 片库索引内存化，列表/筛选 SSR 单次查询返回；转码并发受 `TRANSCODE_MAX` 约束，默认值面向低配 NAS |
| 资源 | 单二进制 + ffmpeg；可选能力缺省不占资源；缩略图按需生成不阻塞扫描 |
| 可靠性 | 文件监听 + 定时兜底双保险；转码失败自动重试一次再回退原画；外部依赖失败静默降级不阻断主流程 |
| 安全 | 路径穿越白名单、签名 Cookie、口令哈希、失败限流、开放重定向防护、panic 恢复 |
| 可移植 | 纯 Go 驱动无 CGO，静态编译；Docker 多阶段构建，PUID/PGID 适配挂载权限 |
| 可维护 | SSR + go:embed；配置全走环境变量；中文注释；HTTP 测试覆盖关键渲染与状态码 |
| 兼容 | 桌面/移动响应式；MP4/WebM 直解，其余靠转码或下载；API 契约与 URL 向后兼容 |
| 可观测 | `/healthz`、请求日志、转码/批量任务进度可轮询 |

## 8. 全局验收基线（Definition of Done）

1. `go build ./... && go vet ./... && go test ./...` 全部通过。
2. 新增/改动模板经真实路由 render 验证（go build 不校验模板语法）。
3. 静态资源（CSS/JS/模板）变更同步升级 `sw.js` 的 `CACHE_NAME` 并更新 PWA 测试断言。
4. 可选能力变更同时验证"启用"与"未启用降级"两条路径。
5. 安全相关变更覆盖越权/穿越/限流的测试断言。
6. 注释、用户文案、提交信息中文；提交信息不含"第 N 轮/期"等无业务含义字样。

## 9. 成功度量（指标体系）

个人产品无在线埋点，采用"可观测信号 + 数据导出"的轻量度量：

- **采用度**：开启 `DB_PATH` 的比例、收藏/清单/评分等持久化功能的记录量（`/stats`、数据健康页可得）。
- **观看体验**：续播命中率（有进度记录视频占比）、看完率（completed 标记）、平均播放次数（WatchStats）。
- **转码健康**：转码会话数、排队（429）频率、失败回退原画次数、平均空闲回收时长（转码管理页）。
- **库一致性**：孤儿记录/孤儿缓存清理量、定时兜底扫描修正的条目数（数据/缓存健康页）。
- **分享安全**：口令失败限流触发次数、过期清理条数（分享管理中心）。
- **质量内建**：CI 门禁通过率、HTTP 测试覆盖的关键页面/状态码数量。

## 10. 风险与约束

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 低配 NAS 转码打满 CPU | 整机卡顿 | 并发上限、空闲回收、VAAPI、默认不启用 ABR、建议局域网使用 |
| 网络盘文件事件丢失 | 片库不一致 | 定时全量兜底 + 手动 rescan + 孤儿清理 |
| TMDB 不可达/限流 | 刮削失败 | 本地 NFO 优先、503/502 降级、批量节流与单任务 |
| 持久化未启用导致功能缺失 | 用户困惑 | 统一 503 + UI 隐藏 + 友好文案，降级矩阵明示 |
| 单密码无多用户 | 无法精细授权 | 当前定位个人/家庭；多用户/RBAC 留待路线图评估，不影响现架构 |
